# Flowchart Drawer 🔷

Flowchart Drawer는 중학교 1학년 '정보' 과목의 알고리즘과 프로그래밍 단원을 위해 설계된 **교육용 순서도 작성 웹 애플리케이션**입니다.

## ✨ 주요 특징 (Features)

* **교육용 필수 기호 5종 지원**: 중학교 교육과정 성취 기준에 맞춘 핵심 도형(시작/끝, 입출력, 처리, 판단, 흐름선)만을 제공하여 인지적 부담을 최소화했습니다.
* **직관적인 드래그 앤 드롭**: React Flow 기반의 매끄러운 캔버스 조작과 자동 스냅(그리드)을 통해 깔끔한 순서도 작성을 지원합니다.
* **오류 검증 (Validation)**: 시작/끝 기호 누락, 끊어진 선 등 알고리즘 로직의 구조적 오류를 제출 전에 검사해 줍니다.
* **시각적 실행 시뮬레이터**: 작성한 순서도의 흐름선을 따라 단계별로 하이라이팅되어 논리적 흐름을 눈으로 확인할 수 있습니다.
* **오프라인 / 로컬 스토리지 기반**: 학생들의 개인정보(학번, 이름)와 작성 데이터는 외부 서버로 전송되지 않으며, 사용자 브라우저(로컬 스토리지)에만 안전하게 보관됩니다.
* **반응형 UI/UX**: 크롬북, 태블릿, 분할 화면(Split View) 등 좁은 화면에서도 캔버스를 가리지 않고 사이드바가 오버레이(Drawer) 형태로 동작하며 원활한 실습 환경을 제공합니다.
* **결과물 내보내기**: 완성된 순서도를 학생 이름/학번 워터마크가 찍힌 이미지(PNG)로 다운로드하여 구글 클래스룸이나 e학습터 등에 즉시 제출할 수 있습니다.

## 🛠 기술 스택 (Tech Stack)

* **Frontend**: React 19, TypeScript
* **State Management**: Zustand
* **Flowchart Engine**: `@xyflow/react` (React Flow)
* **Styling**: Tailwind CSS
* **Build Tool**: Vite

## 🚀 시작하기 (Getting Started)

### 사전 요구사항
* Node.js (v18 이상 권장)
* npm 또는 yarn

### 설치 및 실행

```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm run dev

# 프로덕션 빌드
npm run build
```

## 🔒 개인정보 및 보안
이 애플리케이션은 서버리스(Serverless) 프론트엔드 환경에서 동작합니다. 입력된 모든 정보와 그려진 순서도는 외부 서버로 전송되지 않으며, '초기화' 버튼을 누르면 기기 내의 로컬 캐시(LocalStorage)까지 완벽하게 소멸되어 공용 PC에서도 안전하게 사용할 수 있습니다.
